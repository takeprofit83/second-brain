## Key gotchas learned this session (all in `feedback_classifier_blocks_prod_writes` memory + `Atlas_Technical_Documentation.md` §31–32)

- **Execute Workflow node's "Workflow Inputs" schema auto-sync can get permanently stuck** in this n8n version — the refresh icon / "Refresh Input List" / "Add All Inputs" menu options simply don't pick up a newly-added sub-workflow input, even against a temporarily-fixed (non-expression) workflow ID. When stuck, patch `workflowId` + `workflowInputs.value` + `workflowInputs.schema` directly via the n8n public API rather than continuing to fight the UI.
- **n8n's `fx`-toggled expression fields auto-prepend `=`** — pasting text that already starts with `=`, or pasting a plain literal ID while `fx` is still toggled on, produces a broken `==`/invalid value. Give plain text without a leading `=` for `fx` fields; toggle `fx` off when a field should hold a literal value.
- **Newly duplicated n8n workflows are inactive by default.** An `Execute Workflow` node calling one fails with "Workflow is not active and cannot be executed" until manually activated — even though the sub-workflow is never triggered on its own and this requirement isn't obvious.
- **Piping non-ASCII text through PowerShell into an external process corrupts it** (`Get-Content -Raw -Encoding UTF8 | ssh ... "cat > file"`) — PowerShell re-encodes piped text via the console codepage regardless of source encoding. Use a base64 round-trip instead for anything non-ASCII.
- **n8n execution data in Postgres (`execution_data.data`) is a flat array with integer-string cross-references**, not plain nested JSON — `{"message":"25"}` means "look up array index 25," not literal value `"25"`. Grepping for a key only returns the reference number; the whole array has to be read and indices resolved manually.
- Plain-text/code fields (Code node JS bodies, single expression boxes) edit reliably by hand in the n8n UI — the UI friction this session was specific to *structured* field lists (Form Trigger's field editor, Execute Workflow's schema-driven input mapper).
