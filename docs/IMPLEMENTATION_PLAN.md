## Детальное описание фаз

### Фаза 1: Замыкание петли бесшовного перехода (Context Resume)
**Цель:** Устранить главный источник трения — ручной перенос контекста при смене нейросети. Обеспечить подхват работы в новом чате в один клик.

* **Задачи:**
  1. Создать воркфлоу `Atlas - Context Resume` в n8n (по спецификации §36 Atlas Tech Docs): чтение последнего `.md` из GitHub API по проекту, упаковка в handoff-промпт, ответ вебхуком.
  2. Добавить обработку `?action=resume` в существующую Relay-страницу (`tangerine-vps`).
  3. Собрать единый букмарклет для браузера (`Atlas: Подхватить контекст`), совместимый с ChatGPT, Claude, DeepSeek, Gemini, Qwen.
* **Зависимости:** Существующий n8n, доступ к GitHub API, работающая Relay-страница.
* **Критерии готовности (DoD):**
  * В ChatGPT захвачен тестовый диалог через букмарклет захвата.
  * В новой чистой вкладке Claude.ai нажат букмарклет `Atlas: Подхватить контекст`.
  * Стартовый промпт с актуальным конспектом автоматически появился в поле ввода Claude.ai без ошибок CSP.
  * Claude корректно отвечает, подтверждая понимание переданного контекста.
* **Точка отката:** Если букмарклет или воркфлоу дают сбой, существующий Capture Pipeline не затрагивается. Возврат к ручному копированию из файла.

---

### Фаза 2: Активация слоя синтеза знаний (Wiki Layer в n8n)
**Цель:** Прекратить накопление «мертвых» разрозненных конспектов. Начать автоматически синтезировать из них живую персональную вики в папке `Knowledge/`.

* **Задачи:**
  1. Импортировать готовые JSON-файлы из `second-brain/Projects/Atlas/tools/wiki-layer/` в n8n (`atlas-wiki-ingest`, `atlas-wiki-query`, `atlas-wiki-lint`).
  2. Настроить учетные записи (GitHub API credential, Header Auth).
  3. Соединить выход воркфлоу `Atlas - Kie Adapter` (после `Create a file`) с вызовом вебхука `atlas-wiki-ingest`.
  4. Провести тестовый прогон линтера `atlas-wiki-lint`.
* **Зависимости:** Завершение Фазы 1, кредиты на балансе Polza.ai / OpenRouter.
* **Критерии готовности (DoD):**
  * После захвата диалога в папке `Knowledge/` автоматически появляется или дополняется страница темы (например, `Knowledge/docker-setup.md`).
  * Файл `Knowledge/index.md` автоматически пополняется новой ссылкой в формате `[[wikilink]]`.
  * Запрос к вебхуку `atlas-wiki-query` возвращает обоснованный ответ по накопленным знаниям.
* **Точка отката:** Отключение триггерной ноды в n8n; откат изменений в `Knowledge/` через `git revert` в репозитории.

### Фаза 3: Стандартизация агентских контрактов и UI
**Цель:** Унифицировать правила работы для любых подключенных локальных сред (Claude Code, Antigravity, Cursor) и подготовить визуальное отображение.

* **Задачи:**
  1. Сформировать `docs/AGENT_CONTRACT.md` — исчерпывающие правила для любого ИИ-ассистента: где брать контекст, как оформлять изменения, как передавать задачу.
  2. Настроить автоматический хук/инструкцию для локальных агентов: при старте в директории `Atlas` агент первым делом считывает последний лог и подтверждает статус.
  3. Открыть папку `second-brain/` в приложении Obsidian (по желанию пользователя), проверить отображение графа знаний `[[wikilinks]]`.
* **Зависимости:** Фазы 1 и 2.
* **Критерии готовности (DoD):**
  * Новый диалог в локальном агенте начинается без ручного погружения: агент сам видит последний лог и формулирует текущий статус.
  * Файлы `PROJECT_PRINCIPLES.md` и `AGENT_CONTRACT.md` соблюдаются агентами де-факто.
* **Точка отката:** Возврат к точечному `CLAUDE.md`.

### Фаза 4: Развитие интерфейсов (MCP / Telegram / RAG)
**Цель:** Расширить каналы взаимодействия с AI-OS за пределы браузера и рабочего ПК.

* **Задачи:**
  1. Создать легковесный локальный MCP-сервер (TypeScript / Python) для Second Brain с инструментами: `search_knowledge`, `get_project_context`, `create_handoff_log`.
  2. Добавить Telegram-бот триггер к n8n (на базе `atlas-wiki-query`) для мобильного доступа к базе знаний со смартфона без необходимости включенного ПК.
* **Зависимости:** Успешная эксплуатация Фаз 1–3.
* **Критерии готовности (DoD):**
  * Локальный агент вызывает инструмент MCP и получает релевантный фрагмент базы знаний.
  * В Telegram-боте на вопрос по проекту приходит точный ответ из `Knowledge/`.
* **Точка отката:** Остановка MCP-процесса / деактивация Telegram-ноды в n8n.
