# Конспект переписки

## Обсуждаемые темы
- Проблемы с тестовыми данными (наличие null значений).
- Тестирование через реальные данные вместо mock данных.
- Процесс переключения между адаптерами.

## Принятые архитектурные решения
- Временное переключение главного pipeline на адаптер Atlas-OpenRouter Adapter Core для тестирования.
- Использование реальных данных через форму (Test/Production URL) для проверки работоспособности.

## Найденные ошибки и их решения
- Проблема с выводом JSON из-за нулевых тестовых данных. Решение: переключение на работающий адаптер с реальными данными.

## Незакрытые вопросы
- Необходимо ли будет вернуть pipeline обратно на Kie после теста, если он должен оставаться основным по умолчанию?
