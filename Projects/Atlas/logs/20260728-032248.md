# Сводка состояния проекта: Content Factory Workflow

## 1. Текущая архитектура и реализация
Система построена на базе **n8n** как оркестратора процессов.

*   **Интеграция с Google Sheets**:
    *   Лист `Channels`: содержит список источников. Поля: `channel_url`, `enabled` (boolean).
    *   Лист `Videos`: база данных контента. Поля: `video_id`, `title`, `video_url`, `views`, `published_at`, `channel_name`, `status`.
*   **Логика обработки (ETL)**:
    *   Процесс использует цикл `Loop Over Items` для последовательного опроса активных каналов.
    *   **Apify Scraper**: Используется Actor `dev_content_scraper` (или аналогичный для YouTube) с настройками: `maxResultsShorts = 10`, `oldestPostDate = 3 days`, `sortBy = NEWEST`.
    *   **Дедупликация**: На этапе `Filter New Videos` происходит сравнение `video_id` из ответа Apify с массивом уже имеющихся `video_id` в листе `Videos`.
*   **Статусная модель**:
    *   `NEW` (входящие)
    *   `SCRIPT` (в работе AI)
    *   `READY` (готово к генерации)
    *   `HEYGEN` (в генерации видео)
    *   `UPLOADED` (загружено в соцсети)
    *   `DONE` (архив)

## 2. Принятые решения и обоснование
*   **Использование Google Sheets**: Выбрано на этапе MVP для максимальной прозрачности данных и простоты ручной корректировки контент-плана менеджером без обращения к базе данных.
*   **Apify как источник**: Выбран за счет высокой скорости реализации (готовый scraper, не требующий сложной настройки YouTube Data API с квотами).
*   **Статусная модель**: Принята для обеспечения асинхронности (разные сценарии n8n могут работать с разными этапами видео, не блокируя друг друга).

## 4. План дальнейших шагов (Backlog)
1.  **Автоматизация**: Замена `Manual Trigger` на `Schedule Trigger` (интервал: 30–60 минут).
2.  **Валидация контента**: Внедрение узла фильтрации по количеству просмотров (`views > 20000`) перед записью в Google Sheets.
3.  **Обогащение данных**: Добавление сбора метаданных (лайки, длительность) для последующей сортировки по "виральности".
4.  **Обработка ошибок**: Добавление узла `Error Trigger` для уведомлений (например, в Telegram) при сбое доступа к Apify или Google API.
