## 2. Бесплатные решения для ветки «АВАТАРЫ»

Чтобы не платить $30/мес HeyGen, используем бесплатные аналоги с API / Webhook:

### Вариант А: Hedra API (хит для быстрых тестов)
* **Как работает:** Вы загружаете любое фото (хоть свое, хоть сгенерированное нейросетью) + аудиофайл с голосом. Hedra идеально анимирует губы и мимику.
* **Почему удобно:** У них есть бесплатные кредиты, а API принимает прямой webhook с аудио и картинкой.

### Вариант Б: Бесплатный скрипт Python (SadTalker / LivePortrait)
* **Как работает:** Локально или на бесплатном сервере (HuggingFace / Colab) разворачивается Open-Source модель.
* **Плюс в MLM/командах:** Полная независимость от сторонних сервисов. Затраты = 0 рублей навсегда.

## 3. Бесплатные решения для ветки «БЕЗ АВАТАРА» (Динамичный видеоряд)

Этот формат идеален для продуктовых ниш, эстетических видео, экспертных цитат, новостей или MLM-презентаций.

Вся связка собирается **внутри n8n без сторонних платных сервисов**:

### Шаг 1: Озвучка (Text-to-Speech)
* **Инструмент:** **Edge-TTS** (Node.js или Python модуль для n8n) / **gTTS**.
* **Плюсы:** Бесплатно, без лимитов, очень реалистичные русские голоса (например, голоса `ru-RU-DmitryNeural` или `ru-RU-SvetlanaNeural` от Microsoft).

### Шаг 2: Генерация фоновых картинок/видео
* **Инструмент:** **Pollinations.ai**
* **Как работает:** Отправляете простой HTTP GET-запрос вида:
  `[https://image.pollinations.ai/prompt/business_man_working_on_laptop](https://image.pollinations.ai/prompt/business_man_working_on_laptop)`
  Получаете готовую картинку за 2 секунды. Без ключей API и без оплаты.

### Шаг 3: Сборка `.mp4` ролика
* **Инструмент:** **FFmpeg Node** в n8n.
* **Что делает:** Берет полученный аудиофайл, накладывает картинку (или несколько слайдов), добавляет легкий наезд (эффект Zoom/Ken Burns) и отдает готовый `.mp4`.

## 1. Чем заменить HeyGen в n8n (Бесплатные альтернативы)

### Вариант А: CapCut / InShot API (Или генерация через открытые сервисы)
Если вам нужен именно «говорящий аватар» (нейро-ведущий):
* **Hedra (hedra.com)** — дает бесплатные кредиты на генерацию видео из фото и аудио.
* **SadTalker / LivePortrait** — бесплатные открытые модели (Open Source). Их можно развернуть бесплатно через Google Colab или Hugging Face Spaces и обращаться к ним через Webhook/API из n8n.
* **Kling AI / Luma Dream Machine** — дают бесплатные попытки на старте для генерации видео по промптам.

### Вариант Б: Бездикторские форматные видео (Text-to-Video / Slideshow)
Большинство контент-заводов для автоматизации органического трафика вообще не используют аватары. Вместо этого они генерируют **Shorts/Reels на основе динамических картинок и озвучки**:
1. **Текст в Аудио (TTS):** Использование **gTTS** (Google Text-to-Speech) или **Edge-TTS** (бесплатный модуль озвучки от Microsoft с отличным русским голосом).
2. **Картинки:** **Pollinations.ai** — полностью бесплатный API для генерации изображений по промптам без регистраций и ключей.
3. **Сборка видео:** Бесплатный инструмент **FFmpeg** (встроен прямо в n8n или запускается в Docker контейнере) — склеивает аудио и картинки в готовый `.mp4` прямо внутри n8n без сторонних сервисов.

## 2. Локальный/Mock-режим (Для идеальной отладки n8n бесплатно)

Пока вы тестируете саму цепочку (Google Таблицы $\rightarrow$ Парсинг $\rightarrow$ Публикация), вам вообще не нужно генерировать реальные видео.

Вы можете настроить **«Заглушку» (Mock Node)** внутри n8n:
1. Отключите модуль `HTTP | HeyGen Create Video`.
2. Поставьте вместо него обычный узел **Code** или **Edit Fields (Set)**.
3. Задайте ему отдавать готовый тестовый файл (например, ссылку на любое бесплатное 5-секундное видео из Pexels или с вашего Google Диска).
4. Эмулируйте вызов Webhook'а.

> **Плюс метода:** Вы на 100% отладите весь конвейер, логику таблиц, статусы и публикацию в соцсети, не потратив ни одного цента.

## 1. Workflow: `5 HEYGEN | Generate Video` (Отправка сценария)

**Назначение:** Поиск готовых к генерации сценариев в Google Таблицах, скачивание и парсинг документов из Google Drive и отправка запроса в API HeyGen[cite: 1].

### Цепочка работы:
1. **Запуск и чтение данных (`TRIGGER | Manual` $\rightarrow$ `GS | Get Videos`):** Ручной запуск процесса и считывание строк из таблицы **Videos**[cite: 1].
2. **Фильтрация (`IF | Ready For HeyGen`):** Отбираются только те строки, у которых[cite: 1]:
   * Флаг `action_send_heygen` установлен в `true`[cite: 1].
   * Поле `heygen_video_url` ещё пустое[cite: 1].
   * Указана ссылка на документ со сценарием `script_doc_url`[cite: 1].
3. **Загрузка и парсинг сценария:**
   * **`DRIVE | Download Script Doc` & `Extract Script Text`:** Документ Google Docs скачивается в формате plain text и из него извлекается текст[cite: 1].
   * **`SCRIPT | Parse Doc`:** JS-скрипт с помощью регулярок/маркеров выделяет из текста блок **Сценарий:** (между заголовком и CTA) и формирует чистый текст `final_script` для диктора[cite: 1].
4. **Запрос к HeyGen API:**
   * Из вкладки **Settings** считываются параметры (`avatar_id`, ориентация, лимит длительности)[cite: 1].
   * Выполняется `POST`-запрос к `[https://api.heygen.com/v1/video_agent/generate](https://api.heygen.com/v1/video_agent/generate)`[cite: 1].
   * В запрос передается `callback_url` (`/webhook/heygen-result`) и номер строки таблицы `row_number` в качестве `callback_id`[cite: 1].
5. **Обновление статуса (`GS | Mark HeyGen Processing`):** В Google Sheets статус записи меняется на `SENT_TO_HEYGEN`, а флаг `action_send_heygen` снимается (`false`)[cite: 1].

## 2. Workflow: `6 HEYGEN | Получаем видео` (Приём результата)

**Назначение:** Асинхронный прием Webhook-уведомления от HeyGen после завершения рендеринга и сохранение готовой ссылки[cite: 2].

### Цепочка работы:
1. **Приём Webhook (`Webhook`):** Слушает адрес `/webhook/heygen-result` на входящие `POST`-запросы[cite: 2].
2. **Парсинг и проверка данных (`Code in JavaScript`):** Извлекает `video_id`, `callback_id` (номер строки) и итоговую ссылку `video_url`[cite: 2].
3. **Фильтры проверки (`IF | Есть video_id` $\rightarrow$ `IF | Видео готово`):** Проверяет, что видео успешно сгенерировано (событие `video_agent.success`)[cite: 2].
4. **Сохранение ссылки (`GS | Update HeyGen URL`):** Находит нужную строку в Google Sheets по `row_number` и обновляет[cite: 2]:
   * `heygen_video_url` — вставляет ссылку на готовое видео[cite: 2].
   * `status` — меняет на `HEYGEN_DONE`[cite: 2].
