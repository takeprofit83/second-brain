# План тестирования и критерии готовности Context Resume (Фаза 1)

> **Статус:** Фаза 1 — Проектирование плана тестирования  
> **Версия документа:** 1.0 (23 октября 2026 г.)

---

## 1. Проверяемые критерии готовности (Definition of Done)

Фаза 1 считается успешно выполненной только при одновременном выполнении следующих критериев:

- [ ] Воркфлоу `Atlas - Context Resume` импортирован в n8n и находится в активном состоянии.
- [ ] При неавторизованном запросе к вебхуку (без `X-Atlas-Secret` или с неверным ключом) возвращается ошибка `401 Unauthorized` / `403 Forbidden`.
- [ ] При валидном запросе с параметром `project: "atlas"` система возвращает JSON с кодом `200 OK` и заполненными 10 обязательными полями Handoff.
- [ ] Время ответа вебхука не превышает 1.5 секунды (включая обращение к GitHub API).
- [ ] Букмарклет не содержит секретов, паролей или токенов в своём исходном коде.
- [ ] Окно Relay корректно открывается из вкладок всех 4 платформ: **ChatGPT, Claude, DeepSeek, Gemini**.
- [ ] Кнопка «Скопировать контекст» помещает форматированный Markdown-промпт в буфер обмена (`navigator.clipboard`).
- [ ] При вставке скопированного текста (Ctrl+V) в чистый диалог любой из 4 моделей, ассистент подтверждает принятие контекста и называет следующий шаг без галлюцинаций.
- [ ] Никакие существующие боевые воркфлоу (`Atlas - Kie Adapter`, `Atlas - Docs Sync`) не повреждены и сохраняют работоспособность.

## 2. Матрица тестовых сценариев (Test Cases)

### Тест 1: Безопасность и авторизация (Негативные проверки)
* **Шаг 1.1:** Отправить POST-запрос на `/webhook/atlas-context-resume` без заголовков.
  * *Ожидаемый результат:* HTTP 401 / 403, тело ответа не содержит данных репозитория.
* **Шаг 1.2:** Отправить POST-запрос с неверным заголовком `X-Atlas-Secret: bad_value`.
  * *Ожидаемый результат:* HTTP 401 / 403.
* **Шаг 1.3:** Отправить запрос с несуществующим проектом `project: "unknown_xyz"`.
  * *Ожидаемый результат:* HTTP 400 или 404 с сообщением об ошибке, без падения процесса n8n.

### Тест 2: Выдача контекста по проекту Atlas (Позитивная проверка)
* **Шаг 2.1:** Отправить авторизованный запрос `project: "atlas"`.
  * *Ожидаемый результат:* HTTP 200. В поле `filename` указан самый свежий лог (на текущий момент: `20260921-204747-diagnostic-audit-20260921-kie-final.md`). Сырой транскрипт (`-raw.md`) проигнорирован.
* **Шаг 2.2:** Проверить наличие всех 10 секций в поле `prompt`.
  * *Ожидаемый результат:* Все разделы присутствуют, пароли и токены замаскированы как `[REDACTED]`.

### Тест 3: Работа Relay-интерфейса и буфера обмена
* **Шаг 3.1:** Открыть Relay-страницу в браузере в режиме `?action=resume`.
* **Шаг 3.2:** Проверить запрос мастер-кода (при первом запуске).
* **Шаг 3.3:** Нажать кнопку проекта `Atlas`.
* **Шаг 3.4:** Нажать кнопку `[ 📋 Скопировать контекст ]`.
  * *Ожидаемый результат:* Текст успешно скопирован в буфер обмена операционной системы. Появляется визуальное подтверждение («Скопировано!»).

### Тест 4: Кросс-платформенная проверка в моделях
* **Шаг 4.1 (ChatGPT):** Открыть `chatgpt.com`, нажать букмарклет -> скопировать -> вставить в чат -> отправить.
* **Шаг 4.2 (Claude):** Открыть `claude.ai`, нажать букмарклет -> скопировать -> вставить в чат -> отправить.
* **Шаг 4.3 (DeepSeek):** Открыть `chat.deepseek.com`, нажать букмарклет -> скопировать -> вставить в чат -> отправить.
* **Шаг 4.4 (Gemini):** Открыть `gemini.google.com`, нажать букмарклет -> скопировать -> вставить в чат -> отправить.
  * *Ожидаемый результат:* Все 4 модели корректно парсят Markdown, понимают текущую задачу и отвечают строго по существу следующего шага.

## 3. План отката (Rollback Procedure)

Если в ходе внедрения Фазы 1 выявится нестабильность:
1. **Отключение вебхука в n8n:** Перевести воркфлоу `Atlas - Context Resume` в статус `Inactive`. Это моментально закрывает эндпоинт без влияния на остальные процессы.
2. **Откат Relay-страницы:** Возврат исходного файла `atlas-relay.html` на сервере `tangerine-vps` (резервная копия сохраняется перед обновлением).
3. **Состояние данных:** Репозиторий `second-brain` не подвергается модификациям во время тестов на чтение, откатывать коммиты не требуется.
