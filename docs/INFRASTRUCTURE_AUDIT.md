## 3. Детальное состояние подсистем

### 3.1. База знаний и документация (Second Brain)
* **Канонический репозиторий:** `D:\YandexDisk\Atlas\second-brain` (`main`).
* **Ключевые документы системы:**

  * `second-brain/Projects/Atlas/Atlas_Technical_Documentation.md` — детальная спецификация на 36 разделов.
  * `second-brain/Projects/Atlas/Atlas_Project_Log.md` — хронологический лог всех итераций разработки.

  * `Projects/Atlas/logs/` — логи и конспекты сессий (`.md` и `-raw.md`).
  * `Courses/` — материалы обучения и разборы уроков.

  * `Templates/` — шаблоны страниц.

### 3.2. Серверная инфраструктура (Docker-стек)
Задокументирована в `second-brain/Infrastructure/2026-07-24-server-setup.md`:
* **n8n:** Управляет пайплайнами, ограничение файлового доступа смонтировано в `/home/node/files` (хост: `/opt/data/n8n-files`).
* **PostgreSQL:** База данных для n8n (`n8n`).
* **Redis:** Брокер очередей для фоновых задач n8n.
* **MinIO (S3):** Локальное S3-хранилище (версия `RELEASE.2023-06-23T20-26-00Z`, зафиксированная из-за отсутствия инструкций x86-64-v2 на хосте VPS).
* **Nginx Proxy Manager:** Управление SSL и маршрутизацией поддоменов.

### 3.3. Реализованные AI-адаптеры и конвейеры (Atlas)
* **Adapter Core Architecture (ADR-001):** Воркфлоу не вызывают API провайдеров напрямую. Оркестратор передаёт параметры `{ provider, system_prompt, user_input, model }`, адаптер нормализует ответ в единый JSON.
* **Рабочие адаптеры:**
  1. `Atlas-Kie Adapter Core` (дефолтный, OpenAI-совместимый эндпоинт `api.kie.ai`).
  2. `Atlas-OpenRouter Adapter Core` (глобальный каталог моделей, Claude Sonnet 5 и др.).
  3. `Atlas-Polza Adapter Core` (оплата в рублях для РФ, поддержка YandexGPT и каталога 400+ моделей).
* **Capture Pipeline (Захват переписок):**
  * Букмарклеты для 4 платформ: ChatGPT, DeepSeek, Gemini, Qwen.
  * Отдельная Relay-страница (`tangerine-vps`) для обхода ограничений Content Security Policy (CSP) браузеров.
  * Двойная фиксация (ADR-010/§34): формируется структурированный handoff-конспект (`.md`) и полный несжатый сырой транскрипт (`-raw.md`).
* **Автоматические дебаты (`Atlas - Model Relay`):**
  * 6-шаговый диалог между GPT и Claude по заданной теме без участия человека с фиксацией в `Debates/`.

## 4. Что отсутствует или не завершено

1. **Read-пайплайн (Context Resume / Loader):**
   * Захват работает в 1 клик, но обратная вставка свежего контекста в новый чат другой модели пока выполняется пользователем вручную (копирование из файла). Архитектура закрытия этого разрыва разработана (ADR-014 / §36), но не закодирована.
2. **Wiki Layer (Ingest / Query / Lint):**
   * Спроектирован и экспортирован в JSON (`tools/wiki-layer/`), но ещё не импортирован и не активирован в боевом n8n.
3. **Единый агентский интерфейс (MCP):**
   * Локальные агенты (Claude Code, Antigravity) взаимодействуют с базой напрямую через файловую систему. MCP-сервер для формализованного доступа к Second Brain пока отсутствует.
4. **Статус «Яндекс Облака»:**
   * Не подтверждено наличие инфраструктуры Yandex Cloud (Compute / Managed DB / Object Storage), отличной от локального Яндекс Диска.
