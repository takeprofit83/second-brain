### Точка 2 — малина

Рядом с краном:

**Wi-Fi-реле**

Ещё одно Wi-Fi-реле.

### Точка 4 — деревья

Ещё одно.

И всё это:

```text
                    МТС 874FT
                         │
                   Wi-Fi сеть
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
     ESP32              Wi-Fi             Wi-Fi
       │                реле               реле
       │                  │                 │
     насос             малина           деревья

      куб
```

**Проводов между зонами нет.**

Проводка нужна только **локально внутри каждой точки** — например, от Wi-Fi-контроллера до клапана.

```text

                        │

              │         │         │
            клапан    клапан    клапан
```

И тогда даже если:

> ❌ 4G пропал

система полива **продолжит работать локально**.

# 6. Мониторинг связи

Это одна из ключевых задач.

ESP32 должна регулярно сообщать серверу:

> «Я работаю и имею доступ в интернет».

Сервер хранит:

- последнее сообщение;
- время работы ESP32;
- уровень Wi-Fi;
- состояние устройства;
- версию прошивки.

Если сообщения прекратились:

```text
🔴 ДАЧА НЕДОСТУПНА

Последний сигнал:
14:32

Возможные причины:
• отключилось электричество
• пропал 4G
• завис/выключился модем
• ESP32 недоступна
```

И здесь есть важный нюанс:

**мы не сможем по одному heartbeat точно определить причину исчезновения связи.**

Но позже добавим дополнительную диагностику — например, отдельный контроль питания модема и ESP32. Тогда система сможет гораздо лучше различать ситуации.

# 9. Главный принцип системы

Вот это я предлагаю считать нашим **архитектурным правилом №1**:

> **Оборудование можно добавлять, удалять и перестраивать без перепрошивки ESP32.**

Прошивка — универсальная.

Конфигурация — на сервере.

Логика — на сервере.

Физические устройства — подключаемые модули.

Получается:

```text
                ┌───────────────┐
                │     VPS       │
                │               │
                │ Конфигурация  │
                │ Логика        │
                │ Расписание    │
                │ Мониторинг    │
                └───────┬───────┘
                        │
                      Wi-Fi
                        │
                ┌───────▼───────┐
                │     ESP32     │
                │               │
                │ универсальный │
                │ контроллер    │
                └───────┬───────┘
                        │
             ┌──────────┼──────────┐
             ▼          ▼          ▼
           насосы     клапаны    датчики
```

И это уже **не просто автоматический полив**.

Это постепенно превращается в **собственную платформу управления дачей**, которую можно расширять по мере того, как ты физически модернизируешь участок.
