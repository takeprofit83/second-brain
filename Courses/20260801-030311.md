### **КОНТЕКСТ ДЛЯ ПЕРЕДАЧИ (Сводная информация)**

**1. Конфигурация интеграции:**
*   **API HeyGen:** Версия API v3. 
*   **Аутентификация:** Использование API-ключа HeyGen (значение: `[REDACTED]`).
*   **Среда автоматизации:** n8n (версия среды подразумевает возможную необходимость обновления узлов HTTP Request при импорте legacy-workflow).
*   **База данных (Google Sheets):**
    *   Лист `Settings`: Хранилище настроек конфигурации аватара (`avatar_id`, `voice_id` и др.).
    *   Лист `Avatars`: Справочник, заполняемый через API-workflow для маппинга ID.
    *   Лист `Videos`: Очередь задач с полем `heygen_video_url` (ключевое поле для отчетности по диплому).

**2. Решения и обоснования:**
*   API v3 предпочтительнее GUI (неактуальность веб-интерфейса).
*   Гибридная структура (промежуточный лист `Avatars` -> ручное/автоматическое копирование в `Settings`) выбрана для соблюдения требований курса и снижения сложности отладки на этапе обучения.
*   Принята стратегия "Pay-as-you-go" без подписки, с готовностью переключиться на альтернативы (OmniHuman) в случае блокировки функционала со стороны HeyGen.

**3. Статус реализации (на момент передачи):**
*   **Сделано:** Проведен анализ инфраструктуры, импортированы workflow преподавателя, проведена верификация API-эндпоинтов, сформирована структура для дипломной работы.
*   **Не решено:** Финализация цепочки записи параметров напрямую в `Settings`, настройка отказоустойчивости (поллинг `heygen_video_id`).

**4. План следующему исполнителю:**
1.  **Workflow "HeyGen Avatars":** Выполнить запрос к `/v3/avatars/looks` и `/v3/voices` для обновления справочных данных.
2.  **Маппинг:** Синхронизировать полученные данные с листом `Settings`.
3.  **Автоматизация:** Модифицировать workflow для прямой записи ID в `Settings` (исключение ручного труда).
4.  **Отказоустойчивость:** Развернуть и протестировать workflow "7 HEYGEN | Восстановление URL видео" для обработки асинхронных ответов API.

**5. Известные ограничения:**
*   Риск деградации старых версий n8n-нод при работе с API v3.
*   Необходимость контроля баланса аккаунта HeyGen (в консоли разработчика: `[REDACTED]`).
*   Дипломная работа требует заполнения `heygen_video_url`, что делает задачу по поллингу критически важной.
