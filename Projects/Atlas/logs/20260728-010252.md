# Техническое задание: Реализация системы долговременной памяти (Common AI Memory)

## 1. Концепция и архитектура
Цель проекта — создание независимого от облачных провайдеров слоя памяти для взаимодействия с различными LLM-агентами (ChatGPT, Claude, DeepSeek, Cursor).
*   **Архитектурный стандарт:** **Model Context Protocol (MCP)**.
*   **Метод хранения:** Локальный стек (SQLite) для обеспечения приватности и нулевых затрат на хранение.
*   **Метод доступа:** Асинхронные запросы от клиента к локальному серверу по протоколу MCP.

## 2. Выбранный технологический стек
*   **Core Engine:** `ai-memory` (на языке Rust).
    *   *Обоснование:* Высокая производительность, поддержка 17 методов управления памятью (CRUD, поиск по смыслу, тегирование), точность извлечения контекста — 97.8%.
*   **Storage:** SQLite. 
    *   *Обоснование:* Файловая БД, которая легко бэкапится и переносится.
*   **Интеграционный слой:** 
    *   **Cursor IDE:** Подключение локального MCP-сервера в настройках `MCP Servers`.
    *   **Веб-интерфейсы:** Использование расширения **GLIA** для браузеров (Chromium-based), обеспечивающего мост между веб-чатами и локальными данными.

## 3. Статус проекта: Что сделано
*   **Анализ выбора:** Проведена оценка доступных решений (Hippocampus, mwe-mcp, Nexus, ai-memory). Выбрана комбинация `ai-memory` для серверной части и `GLIA` для пользовательского UI.
*   **Верификация:** Подтверждена возможность работы Cursor (бесплатная версия) с MCP-серверами. 
*   **Финансы:** Разработана стратегия работы без платных подписок (использование локальных ресурсов + веб-версии ИИ).

## 4. План дальнейших шагов (Roadmap)
1.  **Установка и настройка окружения:**
    *   Установить Rust/Cargo (для сборки `ai-memory`).
    *   Инициализировать SQLite базу данных.
    *   Настроить порт `localhost` (по умолчанию `8080`) для работы MCP-сервера.
2.  **Интеграция с IDE:**
    *   Добавить путь к MCP-серверу в настройки `Cursor` -> `Features` -> `MCP`.
    *   Провести тест коннекта (проверка доступности инструментов сервера через команду `mcp-inspector` или логи Cursor).
3.  **Настройка браузерного слоя:**
    *   Установить расширение **GLIA**.
    *   Настроить эндпоинты в расширении для синхронизации с запущенным локальным сервером.
4.  **Сценарии использования (Workflow):**
    *   Реализовать процесс «запоминания»: отправка команды `/remember <информация>` из чата в MCP.
    *   Реализовать процесс «запроса»: автоматическое извлечение контекста перед ответом ИИ.

## 5. Нерешённые вопросы и ограничения
*   **Grok:** Полностью исключен из автоматизации из-за отсутствия поддержки MCP и API. Работа с ним требует ручного копирования контента.
*   **Конфликты форматов:** Необходимо следить за тем, чтобы структура данных в SQLite (schema) соответствовала версии `ai-memory`.
*   **Безопасность:** Локальная база SQLite не зашифрована по умолчанию. При необходимости обеспечения физической безопасности данных требуется настройка шифрования (например, SQLCipher).
*   **Latency:** При большом объеме БД SQLite время ответа на запрос может увеличиться, потребуется оптимизация индексов.
