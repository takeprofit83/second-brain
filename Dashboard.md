## 🔄 Как устроен цикл совместной работы с ИИ

1. **Человек (Вы):** Открываете эту базу в **Obsidian** (папка `second-brain` как Vault), читаете заметки, редактируете цели, смотрите граф связей.
2. **Агенты (ChatGPT, Claude, DeepSeek, Gemini, Kimi):**
   - Получают контекст проекта через **Atlas Companion Extension** (вкладка *«Подхватить»*).
   - В промпте получают строгую директиву: **не переспрашивать**, а сразу выполнять *«Следующий конкретный шаг»*.
   - Выполняют работу и формируют отчёт.
3. **Обратная связь:** Вы нажимаете *«Сохранить отчёт»* в расширении -> отчёт записывается в GitHub -> локальный синхронизатор подтягивает его на ваш диск -> файл сразу появляется в Obsidian!
