# Knowledge Index

Оглавление персональной вики. Каждая строка — одна тематическая страница в `Knowledge/`, добавляется автоматически воркфлоу `Atlas - Wiki Ingest` (см. `Projects/Atlas/Atlas_Technical_Documentation.md` §35) на основе новых конспектов из `Projects/Atlas/logs/` и `Courses/`.

Формат страницы — `Templates/wiki-page-template.md`. Ручные правки допустимы, но `Atlas - Wiki Lint` может дописывать недостающие строки автоматически (см. §35.3) — не полагайтесь на то, что порядок строк стабилен.
