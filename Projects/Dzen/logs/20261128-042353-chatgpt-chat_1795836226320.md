## 1. Краткое резюме

**Проект:** создание премиального сайта платформы «Дзен-Автор» с кинематографичной 3D-графикой, сложными интерактивными анимациями и демонстрацией автоматизированной цифровой редакции.

**Главное решение:** художественная концепция сайта из 13 секций согласована. Повторное проектирование и поиск новых визуальных решений не требуются.

Основная незавершённая задача — восстановление и экспорт ранее созданных и утверждённых интерактивных прототипов.

**Что достигнуто:**
- Утверждена архитектура из 13 секций.
- Определена дизайн-система.
- Зафиксированы сценарии сложных анимаций.
- Определены тарифы и функциональные требования.
- Разграничены утверждённые прототипы и технические сборки V1/V2.

**Что не завершено:**
- Инвентаризация исходных сообщений.
- Извлечение оригинального HTML, CSS и JavaScript.
- Сбор графических ресурсов и зависимостей.
- Создание 13 самостоятельных HTML-файлов.
- Подготовка комплекта для Codex.

## 2. Ключевые факты и технические решения

### 2.1. Дизайн-система

Название концепции: **Дзен-Автор — Cinematic Intelligence**.

Визуальная идея — автономная цифровая редакция, промышленная эстетика и реалистичная 3D-графика.

| Элемент | Утверждённое значение |
|---|---|
| Фон | `#18181a` |
| Поверхности | `#242426` |
| Разделители | `#414143` |
| Акцент | `#ff5317` |
| Шрифт | Montserrat |
| H1 | 64–76 px |
| H2 | 40–48 px |
| H3 | 22–26 px |
| Основной текст | 16–18 px |

Запрещены:
- Glassmorphism.
- Прозрачные карточки и кнопки.
- Дешёвые градиенты.
- Избыточное свечение.
- Однообразные карточные сетки.
- Декоративные английские надписи.

Оригинальный логотип обязателен. Светящиеся четырёхконечные стеллы допускаются только как дополнительные элементы.

### 2.4. Критически важные анимации

**P02 — Живая статистика**
- Сборка цифр: 1,8 секунды.
- Дыхание и волны частиц.
- Увеличение выбранного показателя на 4–5%.
- Повторное появление секции не запускает сборку заново.

**P04 — Морфинг частиц**
- Около 2900 светящихся частиц.
- Четыре состояния: тема → текст → оформление → публикация.
- Управление наведением, фокусом и нажатием.
- Автоматическая карусель запрещена.

**P07 — Автоматизация**

Последовательность демонстрации:

1. Создание.
2. Медиатека.
3. Календарь.
4. Публикация.
5. Пополнение очереди.

**P12 — Финальный механизм**
- Объёмный оригинальный логотип.
- Концентрические вращающиеся кольца.
- Сегментированные орбиты.
- Реакция механизма на наведение на CTA.

## 3. Технические ограничения

Это обязательные условия реализации.

1. V3 не использовать как визуальную основу.
2. V2 считать исключительно техническим черновиком.
3. Не заменять утверждённые прототипы упрощёнными аналогами.
4. Сохранять исходную функциональность сайта.
5. Не ломать SEO, регистрацию, тарифы и динамическую статистику.
6. Сохранять интеграции блога и `/stats.json`.
7. Использовать только вымышленные демонстрационные данные.
8. Не публиковать личные данные со скриншотов.
9. Приостанавливать анимации за пределами видимой области.
10. Проектировать каждую секцию индивидуально, без глобального масштабирования.

**Главный принцип:** утверждённый прототип — эталон визуального и интерактивного поведения. Текстовая концепция служит спецификацией, а V1/V2 — только техническими материалами.
