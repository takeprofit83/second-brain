Давай перейдем к реализации последнего блока первого этапа — **автоматическому сохранению логов**.

### Решение архитектора по файловой системе
Чтобы n8n мог писать файлы на сервер, нам нужно примонтировать папку сервера в контейнер. Сейчас контейнер `n8n` не «видит» `/opt/atlas/logs/` на хосте.

#### Шаг 1: Остановка n8n
В терминале сервера выполни:
```bash
cd /opt/apps/n8n
docker compose down
```

#### Шаг 2: Изменение конфигурации
Открой файл конфигурации:
```bash
nano /opt/apps/n8n/docker-compose.yml
```
Найди блок `volumes:` и добавь в него новую строку, чтобы получилось так:
```yaml
    volumes:
      - /opt/data/n8n:/home/node/.n8n
      - /opt/atlas/logs:/opt/atlas/logs
```
*Это примонтирует папку сервера `/opt/atlas/logs` внутрь контейнера по тому же пути.*

Сохрани (Ctrl+O, Enter, Ctrl+X).

#### Шаг 3: Запуск и проверка
```bash
docker compose up -d
```
Теперь n8n видит эту папку. В n8n нода **Write File to Disk** должна заработать с путем:
```text
/opt/atlas/logs/{{ $json.created_at.replace(/[:]/g,"-") }}.md
```

**Результат:**
1. Запусти workflow.
2. Проверь на сервере наличие файла:
```bash
ls /opt/atlas/logs/
```

**Если файл появился — напиши «Файл успешно создан».** После этого мы закроем этот этап и перейдем к созданию модуля `Kie Adapter`.
