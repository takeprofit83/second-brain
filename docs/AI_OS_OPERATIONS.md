# AI-OS Operations Manual (Руководство по эксплуатации и ежедневному использованию)

**Версия:** 1.0  
**Дата:** 2026-10-23  
**Целевая аудитория:** Пользователь AI-OS, операторы автоматизации, ИИ-ассистенты  

---

## 1. Быстрый старт (Ежедневный сценарий работы)

AI-OS разработана так, чтобы минимизировать рутинные действия при переключении между искусственными интеллектами.

### Шаг 1: Подхват контекста в новом чате (Resume)
1. Откройте любой веб-чат: [Claude](https://claude.ai/new), [ChatGPT](https://chatgpt.com), [DeepSeek](https://chat.deepseek.com), [Gemini](https://gemini.google.com/app), [Qwen](https://chat.qwen.ai) или [Kimi](https://kimi.moonshot.cn).
2. На панели расширений браузера кликните иконку **Atlas AI-OS**.
3. Расширение автоматически определит сайт (например, зелёный бейдж `Claude` или `ChatGPT`).
4. Нажмите кнопку нужного проекта (например, **Atlas**, **Курс**, **Дзен**, **Настя**, **Дача** или **Другое**).
5. Контекст мгновенно загрузится из Second Brain:
   - Автоматически скопируется в буфер обмена.
   - Нажмите кнопку **"⚡ Вставить прямо в чат"**, и промпт появится в поле ввода!
6. Отправьте сообщение модели. Модель сразу поймёт, над чем ведётся работа, какие решения приняты и какой следующий шаг.

---

### Шаг 2: Выполнение работы моделью
Модель выполняет задачу: пишет код, готовит контент-план, анализирует данные или проектирует архитектуру.

---

### Шаг 3: Сохранение результатов и отчёта (Reverse Save)
По завершении сессии попросите модель:
> *"Сформируй итоговый отчёт о выполненной работе по формату AI-OS Report (краткое резюме, выполненные действия, принятые решения и следующий шаг)."*

Затем сохраните его в Second Brain:
- **Способ А (через расширение):**
  1. Откройте расширение Atlas -> вкладка **"📝 Отчёт"**.
  2. Если модель выдала JSON, просто вставьте его в поле *"Или вставьте полный JSON-отчёт ИИ"* — все поля заполнятся автоматически!
  3. Либо впишите 1-2 предложения в поле *"Что сделано"* и *"Следующий шаг"*.
  4. Нажмите **"🚀 Сохранить отчёт в Second Brain"**.
  5. Отчёт мгновенно запишется в репозиторий GitHub с генерацией уникального файла и коммита!

- **Способ Б (автоматический захват переписки Capture):**
  1. В расширении перейдите на вкладку **"📤 Захватить"**.
  2. Нажмите **"🔍 Прочитать диалог со страницы"**.
  3. Выберите проект, и полный лог диалога отправится на автоматическую суммаризацию в n8n через модель Kie.ai.

---

### Шаг 4: Бесшовное продолжение в другом ИИ
Перейдите в другой чат (например, из Claude в DeepSeek или Gemini).  
Повторите **Шаг 1**: нажмите кнопку того же проекта.  
Новый чат мгновенно увидит свежий отчёт, сделанный предыдущим ИИ, и продолжит работу с того места, где вы остановились!

## 2. Подключение нового браузера

Расширение работает в любом браузере на базе Chromium (Яндекс Браузер, Google Chrome, Microsoft Edge, Brave, Opera):

1. Откройте страницу расширений:
   - В Яндекс Браузере: `browser://extensions/`
   - В Google Chrome: `chrome://extensions/`
2. Включите переключатель **"Режим разработчика"** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked).
4. Выберите папку: `D:\YandexDisk\Atlas\atlas-extension`.
5. Расширение **Atlas AI-OS Companion** появится на панели браузера. Закрепите его значок.

## 3. Резервный доступ через Букмарклеты и Релей

Если на каком-либо устройстве или браузере нельзя установить расширение:
- Откройте Relay Hub: `http://195.19.12.38/atlas-relay-d42332f0300f625f.html?action=resume`
- Выберите проект и нажмите *"Скопировать в буфер"*.
- Вставьте промпт в любой чат вручную (`Ctrl+V`).

---

## 4. Подключение новой модели или платформы

Чтобы добавить поддержку нового веб-интерфейса чата:
1. Откройте `atlas-extension/popup.js` и `extractor.js`.
2. В массив `PLATFORM_SELECTORS` добавьте селектор поля ввода и сообщений нового сайта.
3. В `manifest.json` в секцию `host_permissions` добавьте домен нового сайта (например, `https://new-ai.com/*`).
4. На странице `browser://extensions/` нажмите кнопку **Обновить** у расширения Atlas.

## 5. Мониторинг и диагностика (Troubleshooting)

### Проверка работоспособности сервисов
- **Вебхук Context Resume:**
  ```bash
  curl -X POST https://n8n.neiroclone.ru/webhook/atlas-context-resume \
    -H "Content-Type: application/json" \
    -H "X-Atlas-Secret: 4a1cc5534eab63ca1ffebb4346c749551e994450e8b9d7fb" \
    -d '{"project":"atlas"}'
  ```
  *Ожидаемый ответ:* `{"status":"ok", "prompt": "..."}`

- **Вебхук Reverse Save:**
  ```bash
  curl -X POST https://n8n.neiroclone.ru/webhook/atlas-reverse-save \
    -H "Content-Type: application/json" \
    -H "X-Atlas-Secret: 4a1cc5534eab63ca1ffebb4346c749551e994450e8b9d7fb" \
    -d '{"project_id":"other","summary":"Тест","next_step":"Тест"}'
  ```
  *Ожидаемый ответ:* `{"success":true, "commit_sha":"..."}`

- **Проверка статуса n8n на сервере:**
  ```bash
  ssh nikita-vm "docker ps | grep n8n"
  ssh nikita-vm "docker logs n8n --tail 20"
  ```
