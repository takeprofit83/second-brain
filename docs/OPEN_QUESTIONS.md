### Вопрос 1: Роль и статус «Яндекс Облака»
* **Контекст:** В описании архитектора указано: *«Используется Яндекс Облако. Исследовать до изменения»*. При аудите в рабочей папке зафиксирован клиент **Яндекс Диск** (`D:\YandexDisk`), выполняющий локальную синхронизацию файлов.
* **Что нужно уточнить:**
  1. Имелся ли в виду исключительно десктопный клиент **Яндекс Диск** для синхронизации папок?
  2. Или у вас развёрнута отдельная инфраструктура в **Yandex Cloud** (виртуальные машины Compute Cloud, бакеты Object Storage, Managed PostgreSQL), которая пока не связана с репозиторием Atlas?
* **Влияние на решение:** Если используется Yandex Cloud Object Storage, его можно задействовать для хранения тяжелых логов вместо MinIO; если только Яндекс Диск — мы не тратим время на поиск скрытых облачных ресурсов.

### Вопрос 2: Потребность в десктопном приложении Obsidian
* **Контекст:** Репозиторий `second-brain` уже полностью сформирован по стандарту Obsidian (поддерживает внутренние ссылки `[[ссылка]]`, структуру папок и шаблоны).
* **Что нужно уточнить:**
  1. Планируете ли вы открывать `second-brain` в десктопном приложении **Obsidian** как свой основной визуальный интерфейс для чтения заметок и графа связей?
  2. Или вам достаточно работы в веб-интерфейсах, VS Code / Antigravity и автогенерации документов?
* **Влияние на решение:** Если Obsidian планируется как активный рабочий инструмент, нужно заложить базовые плагины (например, Git auto-backup, Dataview) на Фазе 3. Если нет — система остаётся 100% автономной на уровне Markdown-файлов.

### Вопрос 3: Предпочтительный баланс провайдеров для фоновых задач
* **Контекст:** Для фоновых операций синтеза знаний (Wiki Ingest, Wiki Query) требуются вызовы LLM. В Atlas настроены адаптеры:
  * **Kie.ai** (`gemini-2.5-flash`) — самый дешёвый для рутины.
  * **Polza.ai** — оплата в рублях РФ, модели YandexGPT, Claude и др.
  * **OpenRouter** — требует зарубежной оплаты/крипты, прямой доступ к Claude Sonnet 5.
* **Что нужно уточнить:** Какой провайдер вы хотите назначить основным по умолчанию для автоматических задач (например, Polza.ai или Kie.ai)?
* **Влияние на решение:** Позволит сразу прописать корректные ID адаптеров в воркфлоу n8n без риска ошибок `402 INSUFFICIENT_BALANCE`.
