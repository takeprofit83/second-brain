# Развертывание инфраструктуры для AI-проектов

> Дата: 24–25 июля 2026

---

# Цель

Подготовить собственную серверную инфраструктуру для запуска AI-сервисов, автоматизаций и хранения данных.

---

# Что было сделано

## Docker

Установлен Docker и Docker Compose.

Используется как единая платформа для запуска всех сервисов.

---

## PostgreSQL

Развернута база данных PostgreSQL.

Параметры:

- Database: `n8n`
- User: `n8n`

Используется как основная БД для n8n.

---

## Redis

Развернут Redis.

Используется для очередей задач n8n.

---

## n8n

Развернут отдельным контейнером Docker.

Настроено:

- PostgreSQL
- Redis
- постоянное хранение данных
- отдельная Docker Network

---

## MinIO

Развернуто собственное S3-хранилище.

Используется для хранения файлов и дальнейшей интеграции с AI-сервисами.

### Возникшая проблема

Последняя версия MinIO не запускалась.

Ошибка:

```text
Fatal glibc error:
CPU does not support x86-64-v2
```

Причина:

Процессор VPS не поддерживает инструкции x86-64-v2.

### Решение

Использована стабильная версия:

```
minio/minio:RELEASE.2023-06-23T20-26-00Z
```

После смены версии MinIO успешно запустился.

---

## Nginx Proxy Manager

Развернут NPM.

Используется для:

- Reverse Proxy
- SSL сертификатов
- управления поддоменами

Особенность текущего сервера:

Внешний Nginx находится у владельца VPS.

Поэтому ему были переданы:

- необходимые поддомены;
- внутренние порты сервисов.

После добавления правил сервисы станут доступны извне.

# Ошибки, найденные во время настройки

## Ошибка подключения PostgreSQL

```
password authentication failed for user "n8n"
```

Причина:

Пароль пользователя PostgreSQL отличался от пароля, который использовал контейнер n8n.

Проверка:

```bash
docker exec -e PGPASSWORD=******** postgres \
psql -U n8n -d n8n -c "SELECT 1;"
```

Результат:

```
SELECT 1
```

Соединение успешно.

Решение:

```sql
ALTER USER n8n
WITH PASSWORD '********';
```

После изменения пароля n8n успешно подключился.

---

## Ошибка DB_TYPE

Использовалось

```
DB_TYPE=postgres
```

Новая версия n8n принимает только

```
DB_TYPE=postgresdb
```

После исправления контейнер успешно стартовал.
